Що це: Бот для генерації навчальних програм.

Технології: Python, FastAPI, aiogram 3.x, PostgreSQL, Google Gemini API.

Як запустити:

Клонувати репозиторій.

Встановити залежності pip install -r requirements.txt.

Створити файл .env за прикладом (можеш додати файл .env.example з порожніми значеннями GEMINI_API_KEY= та BOT_TOKEN=).

Запустити сервер Uvicorn та бота.
